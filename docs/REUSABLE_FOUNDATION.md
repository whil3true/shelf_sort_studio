# Переиспользуемая основа

| Модуль | Назначение |
| --- | --- |
| `src/platform/Platform.ts` | Загрузка SDK с таймаутами, fallback, типизированные возможности платформы |
| `src/platform/Lifecycle.ts`, `Ads.ts` | Ready, GameplayAPI, причины паузы, cooldown и рекламная транзакция |
| `src/audio/` | Манифест, жестовая разблокировка, независимая громкость и пауза |
| `src/ui/viewport.ts` | Портретный FIT, единые логические координаты и HiDPI |
| `src/platform/Storage.ts` | Локальное хранилище, версия и безопасное восстановление прогресса |
| `src/game/` | Чистые правила Shelf Sort, прогон ходов и solver без Phaser и браузера |
| `.github/workflows/` | Production-проверки и публикация Pages через Actions |

Для новой игры замените игровую модель, визуальную сцену, список ресурсов и формат прогресса. Выберите новый ключ хранилища. Привяжите Ready к первому интерактивному кадру, GameplayAPI к активному игровому экрану и рекламные точки к событиям игры.
