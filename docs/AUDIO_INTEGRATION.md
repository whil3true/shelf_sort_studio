# Оригинальное аудио

В `public/assets/audio/` установлен комплект из семи оригинальных OGG. Манифест `src/audio/AudioAssets.json` активирован. `AudioAssetManifest.ts` читает его и возвращает пути для существующего аудиокода.

| Событие | Файл |
| --- | --- |
| `background_music` | `forget_me_not_in_f_major_looped.ogg` |
| `ui_click` | `click_003.ogg` |
| `item_pickup` | `drop_003.ogg` |
| `item_place` | `drop_002.ogg` |
| `item_invalid` | `bong_001.ogg` |
| `match_three` | `drop_004.ogg` |
| `shelf_reveal` | `drop_003.ogg` |
| `level_complete` | `jingles_PIZZI10.ogg` |

`shelf_reveal` использует тот же файл, что и `item_pickup`. Для совпадений, анимируемых одновременно, играет один эффект.

Комплект установлен через `npm run audio:install`. Скрипт сверил заголовки Ogg и SHA-256 с [реестром доноров](audio.sha256.json). `npm run audio:verify` проверяет установленные файлы. `npm run verify` и `npm run release:zip` дополнительно сверяют семь хешей в production-сборке и в Yandex ZIP.

Музыка запускается после пользовательского жеста и продолжает играть при переходах между экранами. При рекламе, сворачивании и потере фокуса проигрыватель освобождает источник и сохраняет позицию. Громкость музыки и эффектов хранится отдельно.

Playwright проверяет загрузку и воспроизведение оригиналов, переходы, паузы и восстановление позиции, SDK no-fill, игровые эффекты и сохранение громкости. На физическом Android вручную проверьте первый тап, скорость и однократность SFX, отключение медиакарточки в фоне, возврат к музыке после сворачивания и реальной рекламы, а также шов петли.
