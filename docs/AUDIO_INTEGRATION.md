# Подключение оригинального аудио

Ветка `feature/original-audio-integration` готова принять семь оригинальных файлов. Загрузите их прямо в `incoming-audio/` этой ветки с точными именами, включая регистр:

- `forget_me_not_in_f_major_looped.ogg`
- `click_003.ogg`
- `drop_003.ogg`
- `drop_002.ogg`
- `drop_004.ogg`
- `bong_001.ogg`
- `jingles_PIZZI10.ogg`

После загрузки выполните `npm run audio:install` из корня проекта. Скрипт проверит весь комплект по [SHA-256](audio.sha256.json), скопирует файлы в `public/assets/audio/` и только затем включит все события в `src/audio/AudioAssets.json`. При ошибке он перечислит проблемные файлы. Оригиналы в `incoming-audio/` сохраняются. Удалить их из временной папки можно на этапе финальной интеграции после проверки; в коммит с подключённым звуком должны войти копии в `public/assets/audio/` и активированный манифест.

До установки игра работает без звука. Отключённый манифест исключает создание аудиоплеера, AudioContext и запросы к OGG. В режиме с включённым манифестом `npm run audio:verify` проверяет наличие и целостность всех ресурсов. Эту проверку вызывают также `npm run dev` и `npm run build`.

| Событие | Файл |
| --- | --- |
| `background_music` | `forget_me_not_in_f_major_looped.ogg` |
| `ui_click` | `click_003.ogg` |
| `item_pickup` | `drop_003.ogg` |
| `item_place` | `drop_002.ogg` |
| `item_invalid` | `bong_001.ogg` |
| `match_three` | `drop_004.ogg` |
| `shelf_reveal` | `drop_003.ogg` |
| `level_complete` | `jingles_PIZZI10.ogg` |

Для открытия заднего ряда используется эффект взятия товара. Совпадения, анимируемые одновременно, звучат один раз. Музыка запускается после доверенного жеста и продолжает играть при навигации. При рекламе и уходе в фон плеер освобождает источник и после возврата продолжает с сохранённой позиции.

После установки запустите `npm run verify` и `npm run test:e2e`. Вручную проверьте в Android Chrome первый тап, петлю музыки, переходы, оба ползунка, сворачивание браузера и отсутствие карточки медиаплеера в фоне. В черновике Яндекс Игр проверьте восстановление после рекламы и no-fill. Источники и лицензии перечислены в [AUDIO_LICENSES.md](AUDIO_LICENSES.md).
