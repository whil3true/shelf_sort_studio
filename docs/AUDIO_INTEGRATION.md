# Подключение аудио

1. Положите лицензированные файлы в `public/assets/audio/`. Имена перечислены в README этого каталога. Музыку подготовьте с бесшовной петлёй.
2. В `src/audio/AudioAssetManifest.ts` поставьте `enabled: true` только у загруженных файлов. Если используете другой формат, подставьте имя и расширение в `file`. Проверьте поддержку формата в Safari, Chrome и Firefox.
3. Выполните `npm run verify` и запустите `npm run preview`. Проверьте первый тап, громкость каждой группы, переходы между экранами и паузу при рекламе и сворачивании.
4. Соберите новый архив через `npm run release`. Зафиксируйте лицензии рядом с файлами, если их условия требуют указания авторства.

Музыка живёт в одном экземпляре на протяжении сеанса. Эффекты включаются после жеста через Web Audio. Отключённые записи пропускаются до создания медиаресурса и сетевых запросов.
