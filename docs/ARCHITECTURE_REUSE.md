# Решения из донорских проектов

Сравнены ветки [Cozy Gallery](https://github.com/whil3true/pairs_and_paths/tree/529ed47) и [Block Workshop](https://github.com/whil3true/block_workshop/tree/867c0d1). Заимствованы архитектурные решения. Типы, игровая модель и ресурсы Shelf Sort Studio разработаны для этого проекта.

| Подсистема | Cozy Gallery | Block Workshop | Реализация |
| --- | --- | --- | --- |
| Bootstrap и готовность | `main.ts`, `GameReady.ts`, асинхронная подготовка до Game Ready | `main.ts`, fallback и выбор языка до первого экрана | Инициализация SDK перед Phaser, Ready после первого отрисованного меню |
| Портретный Canvas | Логическая композиция 480×800 и физический масштаб | Портретный Phaser и контроль взаимодействия с canvas | FIT, центрирование в safe area, физическое разрешение до 2× |
| Навигация и UI | Самостоятельные сцены меню и игры, общая локализация | Жизненный цикл без возврата к заставке, настройки и защита drag | Одна сцена с обычной сменой экранов и модальных окон, постоянные службы |
| Язык и сохранения | Приоритет ручного языка, отдельный адаптер прогресса | SDK-locale и единая модель настроек | Версионный документ с настройками, пройденными уровнями и журналом активной партии |
| Звук | Текстовые `AudioRuntime`, `HtmlAudioOutput` и жестовая разблокировка | Текстовые `BrowserAudioLifecycle`, `AudioPausePolicy` и постоянный runtime | Один музыкальный output, Web Audio для эффектов, централизованный манифест и паузы |
| Реклама и жизненный цикл | Game Ready, `YandexPlatform`, завершение показа через callbacks | Тайминг рекламы, независимые причины паузы и охрана ввода | Событийный interstitial после победы, rewarded за подтверждённую подсказку, одна транзакция за раз |
| GitHub Actions | Отдельный workflow Pages и проверка архива | E2E production-сборки и релизный артефакт | Одна сборка для трёх браузеров и ZIP, деплой только из `dev` |

Снимки состояния в Undo используют неизменяемую модель поля. После reload те же снимки восстанавливаются проверенным воспроизведением журнала. Обновление списка пройденных уровней и удаление активной партии происходят одной записью. SDK, фон и реклама могут перекрываться, состояние ввода и звука восстанавливается после снятия всех активных причин.
